USING THE FILES
Extract outside your scanned media library and review episode-mapping.csv.
Back up existing NFOs before replacing any. Copy metadata/tvshow.nfo into your
series folder. For a single-season layout, put season.nfo in your season folder.
Copy each episode NFO beside its matching video. Its basename must exactly
match your video, for example Bleach 01 Soul Reaper.mkv and
Bleach 01 Soul Reaper.nfo. If yours differ, rename the NFO copy to match.
The metadata/Season 01 folder here is package organization, not an instruction
to move or rename your videos. Existing videos and subtitles need no changes
merely to copy sidecars. Test one chapter and verify recognition before bulk use.
Keep TYBW, alternate versions and bonus content separate from this 35-part map.

STATUS AND LIMITATIONS
These are the latest accessible staged NFOs, preserved byte-for-byte, plus the
original season NFO. This bundle finalizes packaging, not live deployment.
The recorded October 29 pilot imported chapter 1's title/plot, but still showed
Season Unknown. A complete 35-chapter Jellyfin import and a season-grouping fix
have NOT been verified. The server was not changed or revalidated for this ZIP.
Season 1 is a library-organization choice. Filename/title spellings are retained,
including Arancars and the Uryu's filename / Uryus display-title difference.
Episode lists and percentages match all 35 supplied guide groups in order;
repeated source episodes and unusual ordering are intentional, not errors to
sort away. Exact retained scenes/timestamps were not checked against video.
Plots should therefore be treated as helpful summaries, not scene-level proof.
NFOs include lockdata=true and omit external provider IDs. This does not prove
that Jellyfin will clear existing incorrect IDs or avoid every online match.
